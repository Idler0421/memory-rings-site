폰을 바꿀 때 데이터는 어떻게 옮기나요?

이전 폰에서 설정 → 백업 내보내기로 파일을 만들어 드라이브·메일 등에 저장하고, 새 폰에서 설정 → 백업 가져오기로 그 파일을 선택하세요. 데이터가 내 기기에만 저장되기 때문에, 앱을 지우기 전에는 꼭 백업해 주세요.

구매했는데 프리미엄이 안 보여요

설정 → 프리미엄 → 구매 복원을 눌러 주세요. 구매할 때 사용한 같은 Apple ID / Google 계정이어야 해요.

프리미엄에는 무엇이 포함되나요?

단어 50개 제한 해제, 범주 기능, 사진 첨부, 추가 테마 색상이 포함돼요. 한 번 결제로 평생 이용하며 구독이 아니에요.

Support & FAQ

How do I move my data to a new phone?

On the old phone, use Settings → Export Backup and save the file to a drive or email. On the new phone, use Settings → Import Backup and pick that file. Your data lives only on your device, so please back up before uninstalling the app.

I purchased Premium but don't see it

Tap Settings → Premium → Restore Purchase. Use the same Apple ID / Google account you purchased with.

What does Premium include?

No 50-word limit, categories, photo attachments, and extra theme colors. It's a one-time purchase for lifetime access — not a subscription.
